# MIC AI · Стенд асинхронного электропривода

Исследовательский стенд для АИР56Б2 (0,25 кВт): управление двигателем, фазные токи, диагностика защит и проверка алгоритмов на реальном оборудовании. Математические модели, сравнительные эксперименты и публикационные материалы см. в [MIC AI Research](https://github.com/11lisov11/mic_theory).

```text
Браузер → Wi-Fi → Arduino Uno Q → UART → Nucleo-G431RB → STEVAL-IPM15B → АИР56Б2
                  веб-интерфейс           управление     через IHM09M2
                  и телеметрия            и защиты
```

## LSO-FOC 2317/2318

Снимок исходного кандидата для стендового прогона АИР56Б2 на 5 Гц с автостопом через 5 секунд. Программные проверки выполнены на ПК. Для этой пары предстоят запись, сверка flash и 64 измерения DWT на Nucleo с выключенным ШИМ.

| Проверка | Результат |
| --- | --- |
| Модель без потерь IPM | Переход в RUN за 98 мс, автостоп на 5000 мс |
| Модель с потерями 10,9 В на плечо | Переход в RUN за 218 мс, автостоп на 5000 мс |
| Модель с потерями 12,46 В на плечо | Защита остановила прогон на 1560 мс |
| Повтор захвата прежнего отказа | При отсутствии намагничивания ШИМ выключается через 400 мс |

При проверке публикации обнаружена гонка STOP из Motor Pilot с подтверждением CLEAR.

Изменения включают ступенчатый предел напряжения вдоль оси d, оценку падения напряжения для наблюдателя и телеметрию намагничивания. Порог фазного тока 1,35 А, бюджет 4000 тактов и предел возраста отсчёта АЦП 2 мс сохранены.

Силовая часть стенда гальванически связана с цифровой землёй. При подаче силового питания связь только по Wi‑Fi. USB, ST‑LINK, Ethernet и заземлённые измерительные приборы к стенду в силовом режиме не подключают.
