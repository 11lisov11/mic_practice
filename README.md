# MIC AI · Стенд асинхронного электропривода

Исследовательский стенд для АИР56Б2 (0,25 кВт): управление двигателем, фазные токи, диагностика защит и проверка алгоритмов на реальном оборудовании. Математические модели, сравнительные эксперименты и публикационные материалы см. в [MIC AI Research](https://github.com/11lisov11/mic_theory).

```text
Браузер → Wi-Fi → Arduino Uno Q → UART → Nucleo-G431RB → STEVAL-IPM15B → АИР56Б2
                  веб-интерфейс           управление     через IHM09M2
                  и телеметрия            и защиты
```

## LSO-FOC 2319/2320

Актуальный кандидат для прогона на 5 Гц с автостопом через 5 секунд опубликован в [ветке LSO-FOC](https://github.com/11lisov11/mic_practice/tree/codex/lso-foc-5hz). Там находятся исходники, отчёт проверки на ПК и [образы кандидата](https://github.com/11lisov11/mic_practice/releases/tag/v0.2.0-lso.1). Аппаратные замеры этой пары ещё предстоят.

## Проверенный выпуск 2111/2112

| Проверка | Результат |
| --- | --- |
| Прошивка стенда | **Uno Q 2111 / Nucleo 2112**, оба образа сверены чтением обратно |
| Вычисления без ШИМ | 64 из 64 замеров DWT. Максимум 3822 из 4000 тактов |
| I/f → FOC | Экспериментальный пуск до 5 Гц. Полный прогон на 2111/2112 ещё не подтверждён |
| Силовая плата | Эксперименты остановлены после просадки линии 15 В. Повреждённый узел и первопричина ещё не установлены |

Силовая часть стенда гальванически связана с цифровой землёй. При подаче силового питания связь только по Wi‑Fi. USB, ST‑LINK, Ethernet и заземлённые измерительные приборы к стенду в силовом режиме не подключают.

Ранние образы, эксперименты и протоколы доступны по [архивному указателю](docs/archive.md). Правила цитирования и происхождение компонентов описаны в [CITATION.cff](CITATION.cff) и [NOTICE.md](NOTICE.md).
