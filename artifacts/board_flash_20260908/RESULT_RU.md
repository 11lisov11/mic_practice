## Не завершено

- Межплатный UART не проверен: проводов нет, принятых пакетов от Nucleo нет. Это не было засчитано как проверенная связь.
- Автозапуск Linux не работает: `chage -l arduino` сообщает `password must be changed`, журнал cron подтверждает `expired password for user arduino`. systemd-установка и перезагрузка требуют аутентификации. После остановки HMI cron не восстановил процесс; приложение запущено вручную штатным скриптом и снова проверено. Поэтому итоговый `unoq_final.json` содержит `pass=false`, несмотря на успешные проверки прошивки и RPC.
- Wi-Fi не настроен: наблюдался только адрес Docker `172.17.0.1`, это не адрес HMI для телефона.
- Часы Linux показывали сентябрь 2025 года вместо сентября 2026. До сбора экспериментальных данных требуется синхронизация. Отчёты содержат отдельно время ПК и платы.
- Холодная загрузка без USB, измерения с IPM, реальный аварийный останов и вращение двигателя не проверены. `hardware_validated=false` сохранён.
- Аналоговые значения при отключённом IPM не являются измерением напряжения DC-шины или токов двигателя.

## Следующие действия

1. Завершить первоначальную настройку UNO Q со сменой пароля и Wi-Fi в Arduino App Lab, не запускать чужие скетчи. Официальное описание первого запуска: https://docs.arduino.cc/resources/datasheets/ABX00162-ABX00173-datasheet.pdf.
2. Повторить установку Linux-части, проверить автозапуск после перезагрузки и часы. Токен HMI хранится на плате в `/home/arduino/.config/mic-ai/control_token`; в этот отчёт и Git он не включён.
3. При отключённой силовой части и снятом питании логики соединить UNO Q D1/TX -> Nucleo PB7/CN7-21; Nucleo PB6/CN10-17 -> UNO Q D0/RX; GND -> GND. Питания 3V3 и 5V плат между собой не соединять.
4. Вернуть USB-питание только логических плат и повторить чтение с `--expect-uart`. Логический анализатор для первичной проверки не требуется.
5. Только после низковольтной проверки всей связки переходить к отдельному плану проверки силовой части. Этот протокол не разрешает подачу 310 В.

```powershell
py -3 tools/board_bringup_readonly.py --device 2759999497 --expect-uart --output artifacts/board_flash_20260908/unoq_uart_connected.json
```
