## Защитный статус не является ошибкой связи

В телеметрии `mc_status=9`: LINK_OK и FAULT. `mc_fault=5` является
общим кодом ошибки MCSDK в текущем UART-протоколе.

Причина установлена чтением SRAM через ST-Link: `Mci[0].CurrentFaults`
по адресу 0x20000744 равен 0x0004, `PastFaults` также 0x0004.
По `Inc/mc_type.h` текущей прошивки это `MC_UNDER_VOLT`.
Сообщаемое напряжение DC-шины 0 В. При отключённой силовой части
такой статус ожидаем; защита не отключалась и не обходилась.

## Подтверждённое соединение

- UNO Q D1/TX → Nucleo PB7 / CN7-21.
- UNO Q D0/RX ← Nucleo PB6 / CN10-17.
- Общий GND; силовая часть отключена.
- UART 115200, 8N1; рабочие прошивки из ready_to_flash.
