# Восстановление UART, 14 октября 2026

Постоянная рабочая пара Uno2026101413/Nucleo2026101412 записана и проверена.
Nucleo сверена полным чтением памяти; Uno проверена загрузчиком. Интерфейс
восстановился после записи без переподключения USB. Калибровка сохранена;
код ШИМ, измерений, фильтров и защиты совпадает с прежней рабочей парой.

Прежний обработчик разрешал NE после трёх неизменных RUN кадров. Тест воспроизвёл
отказ CRC-корректного пакета при запуске/изменении частоты. В предыдущем силовом
пуске зафиксирован NOISE_REJECTED; исходный отвергнутый пакет отсутствует,
поэтому конкретная ветвь и потеря битов не доказаны.

Теперь чистые кадры связи, включая STOP, подготавливают обработку одиночного NE.
CRC32C, последовательность и проверка команды сохраняются. Повреждённые пакеты
отбрасываются с поиском следующего заголовка; известное отбрасывание допускает
ограниченный пропуск номера. Бюджет восстановления — два события за секунду.
Мусор не применяет команды и не обновляет таймаут300 мс. Устойчивые ошибки,
повторы, необъяснимые скачки номера и серьёзные ошибки UART сохраняют останов.
CLEAR требует чистого пакета.

API публикует `mc_recovered_drops`/`bp_recovered_drops` отдельно от аварий.
Одно отбрасывание сохранено на границе перепрошивки. Ожидаемый таймаут при
записи Uno сохранён в журнале и подтверждён одним STOP/CLEAR при выключенном
силовом. Ожидаемая защита по низкому напряжению осталась видимой.

Прошли2061 проверка кода,344 одиночных повреждения битов,43 положения NE,
вставка/удаление байта в каждом положении, START/изменение частоты/STOP/потеря
силового/таймаут/переполнение времени. Настоящий обработчик Nucleo передаёт
ответы настоящему приёмнику Uno и декодеру HMI; аппаратура и MCSDK моделируются.
Четыре намеренно повреждённые защиты обнаружены. Пять наборов проверок HMI
и42 HTTP-проверки, включая два обычных START/STOP, прошли.

На железе после установки:30.828с,41 отсчёт,+589 корректных ответов, новых
ошибок нет. При выключенном силовом интерфейс продолжает получать диагностику
низкого напряжения. Последнее состояние SAFE/ШИМ0/допуск0/шина2 В/UART fault0.
Запуск нового исправления при работающем инверторе и отключение силового во
время RUN ещё предстоит проверить. Онлайн-ускорение пока не реализовано.

NE сообщает о несовпадении выборок при приёме; сам флаг не доказывает потерю
битов. [ST RM0440](https://www.st.com/resource/en/reference_manual/rm0440-stm32g4-series-advanced-armbased-32bit-mcus-stmicroelectronics.pdf).
Проводимые помехи через питание/землю возможны при экранированных сигнальных
проводах. Это возможный механизм; конкретный источник на стенде не измерен.
[ST AN4694](https://www.st.com/resource/en/application_note/an4694-emc-design-guides-for-motor-control-applications-stmicroelectronics.pdf).
