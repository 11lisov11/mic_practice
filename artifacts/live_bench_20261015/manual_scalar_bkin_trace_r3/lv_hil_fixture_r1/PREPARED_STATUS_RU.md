# Низковольтный BKIN HIL — подготовлен, не прошит

Дата: 2026-10-15. Текущая установленная пара Uno/Nucleo остаётся 2026101507/2026101506.

## Подготовлено

Собран отдельный Nucleo fixture-образ на основе текущего диагностического исходника. Он сохраняет внутреннюю запись PA6/BKIN 1 МГц и добавляет ограниченный внешний тестовый импульс: PC8 Nucleo (CN10-2) с открытым стоком через последовательный резистор 1 кОм к STEVAL TP23; импульс начинается через 800 мс после старта PWM, длится 250 мс и срабатывает один раз за загрузку. Между событиями встроенный DMA-рекордер фиксирует PA6.

В образе действует низковольтная аппаратная оснастка: готовность только после свежей ADC-проверки шины и её стабилизации не выше 10 В, ограничение активного PWM 15 с, снятие только ожидаемого undervoltage; остальные защиты сохранены. Изменены только `Src/main.c`, `Src/mc_tasks.c`, `acim_vf_control.c` и новый `Inc/aux_sd_pulse.h`.

Сборка: 0 ошибок, 0 предупреждений. Хеш BIN: `A9CF1E027DF179C95E33D093758AD2879C86843665139EAC5E07107A98D07089`. Сверка объектных секций прошла: TIM1 Break/Update IRQ, PWM on/off/phase outputs, DP handler и исходник инициализации TIM1 совпадают с установленным диагностическим образом. Пройдены host-проверка bus interlock, пять HMI guard suites и 67 проверок установки/диагностики.

Для совместимости с установленными Uno/HMI на время этой изолированной оснастки сохранён протокольный build ID Nucleo 2026101506. Бинарник отличим по указанному SHA и не является рабочим образом.

## Состояние оборудования

На момент подготовки Uno и Nucleo доступны по USB. HMI отвечает; `SAFE`, PWM=0, телеметрия DC-шины 0 В. Активный флаг MCSDK — только `MC_UNDER_VOLT`; профиль LV заблокирован рабочей прошивкой при обесточенной шине. Низковольтный fixture-образ не прошивался, START не отправлялся, силовое питание не включалось.

## Условия физического HIL перед прошивкой и запуском

- сеть отключена;
- STEVAL J1 физически отсоединён;
- двигатель отсоединён от J3 U/V/W;
- до J4 мультиметр подтверждает DC-шину менее 2 В;
- для теста допускается только вспомогательное J4; после его включения DC-шина должна оставаться не выше 10 В;
- PC8 CN10-2 соединён с TP23 только через 1 кОм;
- никакого силового входа и двигателя в этом тесте.
