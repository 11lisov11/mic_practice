# Следующий шаг для выяснения причины Break

## Что показал последний прогон

В расширенном прогоне Nucleo зафиксировала TIM1 Break / MC_DP_FAULT при
последнем активном отсчёте12.6 Гц. Одновременно UART оставался свежим,
ошибки/CRC/sequence были0. PA6 прочитан HIGH уже при входе в обработчик;
прикреплённый телеметрический контекст устарел на43мс. Текущий пассивный
снимок подтверждает Break, но не сохраняет форму/длину импульса.

## Почему текущий Saleae не подходит под включённым силовым

У обычного Saleae нет гальванической развязки ни между входными каналами,
ни между ними и USB компьютера. Поэтому его нельзя сейчас подключить к PA6
и общей земле Nucleo, пока стенд под напряжением: через USB образуется
проводящая связь с компьютером.

У Uno Q действительно есть USB-C с поддержкой роли USB host, но официальный
Saleae Logic Software не поддерживает ARM Linux, а Saleae указывает, что это
единственное ПО для обмена данными с их приборами. Подключение Saleae к Uno Q
не создаёт работающий автономный регистратор.

Источники производителей:

- [Saleae: входы и USB не изолированы](https://new.saleae.com/support/specifications-hardware/electrical-characteristics/are-the-ground-pins-required-for-each-input-used)
- [Saleae: предупреждение о подключении земли через USB ПК](https://www.saleae.com/support/specifications-hardware/product-comparison-and-selection/safety-and-warranty)
- [Saleae: Logic Software не работает на ARM Linux](https://www.saleae.com/support/troubleshooting/installation-and-launch-issues/can-logic-run-on-arm)
- [Arduino: USB host и USB-C роль Uno Q](https://docs.arduino.cc/tutorials/uno-q/power-specification)

## Вариант с имеющимся оборудованием

Добавить в диагностическую прошивку Nucleo независимый кольцевой DMA-буфер,
который периодически читает только логический уровень PA6/BKIN. При первом
аппаратном Break заморозить буфер до обычной обработки события, записать индекс
DMA, счётчик таймера и статус источника Break. Сохранить исходный механизм
защиты: BKE и DP handler остаются включёнными; запись не командует мотором,
не сбрасывает BIF и не задерживает/маскирует отключение выходов.

Снимок передавать отдельными диагностическими страницами через существующий
пассивный Wi-Fi канал, только когда PWM выключен. Он не должен считаться ACK
командой управления или менять UART-счётчики. Включить идентификатор прошивки,
частоту выборки и тактирования, число валидных отсчётов, позицию кольца,
состояние DMA на останове, TIM1 SR/BDTR/AF1 и CRC полного блока. До выхода
на силовой прогон проверить, что диагностический пакет читается, страницы
собираются полностью и сохраняют контрольную последовательность без искажения.

Текущая CubeMX-конфигурация использует DMA2 Channel2/3 для USART2 RX/TX,
TIM2 в проекте не настроен; Channel1 выглядит свободным по `.ioc`, но его
маршрут DMAMUX, приоритет и конкуренцию на шине нужно проверить по точной
версии STM32G431 до выбора частоты сэмплирования. Поэтому частота и размер
кольца здесь ещё не зафиксированы. Один уровень PA6 покажет длительность
внешнего низкого импульса с разрешением выбранной частоты; он всё равно не
измерит напряжение J4 или фазный ток и не исключит внутренний источник Break.

## Порядок работ

1. Сохранить текущий снимок и защёлкнутую аварию; не посылать CLEAR/START.
2. На текущих исходниках подготовить отдельный кандидат Nucleo с кольцевой
   записью и проверяемым Wi-Fi-декодером. Не трогать Uno, калибровку, закон
   V/f, вход BKIN, фильтры и пороги защит.
3. Проверить конфликт таймеров/DMA, статический объём SRAM и компиляцию.
   До переноса на стенд сверить новые источники, метаданные и образ по SHA.
4. Устанавливать кандидат только при выключенных силовом/J4, отключённой сети
   и независимо проверенной безопасной DC-шине. Для изменения частоты/темпа
   эта запись не нужна; она требуется только для добавления регистратора.
5. После установки оставить все щупы Saleae снятыми, передать питание контроллерам
   автономно, стенд держать закрытым. Один дальнейший старт после анализа
   снимка должен завершаться штатно либо исходной аппаратной защитой; никаких
   автоматических CLEAR и повторных пусков.

Этот план ещё не реализован, не собран и не проверен на стенде. Текущая пара
1505/1504 остаётся установленной. Последняя известная физическая конфигурация:
двигатель подключён, обе платы на повербанке, силовое и15 В включены, PC USB
и все провода Saleae сняты, PWM0, рабочий Break сохранён. При чтении текущих
логов выключать силовое не нужно. Выключение требуется перед любой новой
записью Nucleo через подключённый к ПК программатор.
