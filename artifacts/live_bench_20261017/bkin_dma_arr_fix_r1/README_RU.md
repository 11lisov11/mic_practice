# Исправление DMA-захвата BKIN

В установленной диагностике TIM2 задавался ARR=0. Справочник ST RM0440 указывает, что при нулевом ARR счётчик заблокирован; фактическая запись подтвердила CNDTR=1024 и 0 валидных отсчётов. Кандидат использует PSC=0 и ненулевой ARR для периода 1 мкс.

Меняется только диагностическая настройка таймера в Nucleo. Uno, HMI, UART, ШИМ, управление двигателем и калибровка остаются прежними. Идентификаторы пары сохранены для совместимости протокола; точный новый Nucleo HEX отслеживается SHA-256. Это диагностическая прошивка, она не разрешает силовой пуск.
