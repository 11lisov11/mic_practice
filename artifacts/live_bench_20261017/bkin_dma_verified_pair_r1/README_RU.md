# Диагностический кандидат BKIN с проверкой DMA

Пара подготовлена от рабочей ручной V/f-пары для одной цели: сделать достоверным
1-МГц снимок PA6 перед аварийным BKIN. Предыдущая версия считала 1024 отсчёта
полными по таймеру, даже если DMA фактически не заполнила буфер.

Кандидат сохраняет значение `DMA2_Channel1->CNDTR` и флаги DMA при останове,
вычисляет по ним число действительных отсчётов и проверяет согласованность при
передаче через Uno Q. В упрощённой панели показывается число подтверждённых
отсчётов или ошибка/отсутствие передачи DMA. Схема V/f, формирование ШИМ,
команды управления и точки калибровки не менялись.

Сборки завершены: Uno Q 2026101703 — LLEXT-проверка без замечаний; Nucleo
2026101702 — STM32CubeIDE, 0 ошибок и 0 предупреждений. HEX Nucleo находится в
`build/nucleo/ACIM-NUCLEOG431RB-IPM15B-VF_OL.hex`, образ Uno Q для записи — в
`build/uno/UNOQ_MOTOR.ino.elf-zsk.bin`. Проверка парсера и исходных инвариантов:
17/17. Хеши сборок и исходников записаны в `manifest.json` и build-manifest Uno.

Кандидат не прошит и не испытан на железе. Он не разрешает силовой пуск сам по
себе и не устанавливает физическую причину защиты: цифровой сигнал BKIN не
различает перегрузку IPM, его просадку питания и помеху; ток фаз и напряжение
питания IPM здесь не измеряются.
