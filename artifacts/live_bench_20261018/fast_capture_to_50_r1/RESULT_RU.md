# Прогон к50 Гц: остановлен при разгоне к15 Гц

Один START, без CLEAR/RESET/перепрошивки/изменения калибровки. Платы автономны, J1/J4 включены. Ступени5 и10 Гц достигнуты ивыдержаны по частоте поля минимум2 с; пользователь подтвердил ровное вращение иускорение.

При задании15 Гц произошёл отказ приёма команд Uno→Nucleo: `UV3_BAD_CRC=2`, первый диагностический кодCRC1, sequence196, RUN6. Последний активный отсчёт11,7 Гц, сохранённый reference после выключения13 Гц. Выдержка15 Гц ичастоты20…50 непроверены, более15 Гц незадавалось. После отказа повторногоSTART/CLEAR нет; выходы выключены, fault/ESTOP сохранены.

Это транспортнаяостановка. Оба слотаBreak пусты, SD-волна не получена, MCSDK маски0/0. При активных выборках Vbus319–322 В,48–50 °C. Ответы Nucleo→Uno имеютCRC/sequence ошибок0; отбраковку команд Nucleo это не исключает. Итоговый `mc_bad_cnt=1`; UnoNOISE вырос0→1, Nucleo observedNE1→13, recovered losses1→4.

Код `UV3_BAD_CRC` используется также при нарушении заголовка/синхронизации, поэтому пока не различены электрическое повреждение передачи и дефектприёма/парсера/формирования. Сырой отвергнутый поток Nucleo несохранён. Следующий шаг — получить эти байты ипричины переходов парсера, сохраняя CRC, watchdog и аппаратные защиты. Продолжение до50 Гц в этом прогоне не разрешалось при отказе иневыполнялось.
