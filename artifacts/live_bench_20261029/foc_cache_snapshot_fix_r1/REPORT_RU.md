Первый regularADCfault фиксируется атомарным first-writer CAS в прежних
четырёх E8пакетах, причина9 с отдельной расшифровкой14слов. Различаются:

в диагностике не добавлено. Запись не стирается STOP/CLEAR и более поздними
ошибками; отдельный subtype выводится в API и строке состояния веб-панели.
Это не подменяет algorithm_fault и не выдаёт отказ кэша за MA_CURRENT.
