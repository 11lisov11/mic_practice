# Повтор FOC3011/3012: MA_CURRENT, 30.10.2026

Один START, CLEAR не понадобился: все защиты были готовы, SD HIGH/BIE включён.
После загрузки был выбран VF; FOC2 штатно выбран при SAFE/PWM0 до ARM.
Пять секунд НЕ пройдены. ШИМ остановлен защитой примерно через
1.935130с по30965кадрам АЦП; сеансUno1995мс.
Наблюдатель выполнил1935шагов. Физическое вращение пока не подтверждено.
Последнее задание, записанное контроллером,3,2Гц; это не скорость вала.

## Конкретная причина

Первый сохранённый отказ FT_CONTROL7 / MA_CURRENT2. Вектор Кларка по
номинальным0,04Ом/усилению2,1/3,3В равен1,364988А >1,35А.
ОтсчётыU/V/W=-39/+138/-99; измерена параU1/W2, V реконструирован.
Предыдущий кадр: -21/+88/-67, вектор0,881844А. RawADC изменились
[2090,2136]→[2108,2168], то есть +18/+32отсчёта двух преобразователей.
Последующий кадр уже после выключения выходов помечен invalid и не считается
подтверждением нормального тока до отказа.

Настоящий C ma_control_checked из установленного motor_control.h воспроизвёл
MA_CURRENT на этих отсчётах с прежним1,35А. Исторические X/P/интегралы не
сохранены; тест использует конечный синтетический наблюдатель для проверки
именно ранней токовой ветки, а не всей исторической траектории регулятора.
Это расчёт по шунтам: реальное физическое превышение и ошибка аналогового
измерения пока НЕ разделены, независимого эталона ампер нет.

## Окно и сроки

Кадр принят, epoch согласован; оба JEOS, очереди JSQR пустые.
Зафиксированные CCR[2557,2889,2423], триггер5184. До ближайшего compare
2295тактов=13,5мкс; требуемое settle771тактов, запас1524такта.
Геометрическая проверка всех3плеч проходит, но программный CCR latch не
заменяет осциллограмму силовых фронтов и не подтверждает аналоговое settling.
UPDATE137<2048, возрастADC31,118мкс<187,5; возрастоценки1187,376мкс<2000.
Fastmax4775<5312тактов. Причина здесь не MA_STALE и не подтверждённый
срыв дедлайна. MCSDKmask1 нельзя читать изолированно: обёртка возвращает
MC_DURATION при любом fault регулятора; точный frozen-код указывает MA_CURRENT.

Максимумы observerwall685,671/IRQlower584,371/CPUupper196,524мкс,
queue302,594/resultage809,224мкс относятся к разным вызовам: не складывать.

## Сценарий и сохранность
