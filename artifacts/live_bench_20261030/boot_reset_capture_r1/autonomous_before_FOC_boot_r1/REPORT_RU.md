# Автономная проверка перед FOC

Пользователь подтвердил переход обеих плат на повербанки, отключённые ПК/Saleae, включённые 15 В и выключенный J1. Пуск/RESET не нажимал.

3013/3014 доступны автономно. Проверены свежие ответы, CRC ранней записи reset, совпадение идентификаторов загрузки с исходным снимком, рост времени Nucleo. Запись загрузки осталась той же; вручную новый RESET не требовался и не выполнялся.

SAFE/PWM0, run_id=0, HV не разрешён; около 10 В контроллера. Автоноль готов за 3 блока. Маски аварий, ошибки UART/CRC/последовательности/RPC нулевые. SD HIGH, Break IRQ включён, захват работает и свободен; место захвата АЦП свободно. Расчётный профиль 128/CRC1354279011 и OFF64 проверены, first_fault отсутствует. Источники установленных прошивок сверены по SHA-256 без изменений.

Выполнена только одна штатная команда конфигурации `SET ALGORITHM FOC` через `/api/algorithm`, при выключенном ШИМ. Выбор FOC2 подтверждён последующими ответами. START/CLEAR/ARM/RESET/перепрошивка — 0.

Следующий физический шаг уже запрошен: только J1 через soft-start, остальные подключения не менять, Пуск/RESET не нажимать. Подтверждение J1 ещё ожидается. До него пуск не отправлять. После подтверждения — свежая проверка напряжения/SD/аварий/записи reset, затем один согласованный FOC5Гц/5сек при готовности защит. Старые захваты сохранены, пороги прежние.
