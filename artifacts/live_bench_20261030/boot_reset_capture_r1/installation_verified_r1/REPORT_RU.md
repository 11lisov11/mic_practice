# 3013/3014 записаны и проверены без пуска

Uno 2026103013 и Nucleo 2026103014 установлены: по одной записи каждой платы. Образы проверены чтением обратно; дополнительно Flash Nucleo независимо прочитана через SWD и совпадает с точным HEX с учётом четырёх байтов FF в промежутке HEX. Калибровка не изменилась. Перед записью сохранено 32 КБ RAM Nucleo; все 1 734 ранее зафиксированных файла проверены по SHA-256.

Получены 12 свежих статусов подряд. SAFE, ШИМ выключен, run_id=0, разрешение силового пуска отсутствует. Ошибок CRC/последовательности/UART/RPC не зафиксировано. Автоноль готов за 3 блока, маски аварий 0/0. SD HIGH, Break IRQ включён, захват работает и свободен. В покое выполнены 64 расчётные проверки ядра, first_fault отсутствует, ошибок CPU/IRQ-учёта нет.

Новая запись причины сброса работает: 32 байта из RAM Nucleo совпадают с переданной записью CRC и веб-статусом. В журнале HMI есть MC_BOOT_RECORD. Счётчик сохранённой цепочки 1, исходный RCC_CSR=0x1C000000: NRST/BOR/software. Это первая запись после программирования с накопленными флагами; её нельзя объявлять причиной прежнего непреднамеренного сброса. Метка конкретной MCSDK SW_RESET отсутствует. Аппаратные флаги уже очищены и очистка независимо подтверждена чтением RCC_CSR; причина следующего сброса должна отделяться от исходной записи.

Дополнительных тестовых RESET, CLEAR, ARM и START не выполнялось. Использовались только сбросы, необходимые для записи и запуска записанных образов. Сохранение цепочки через отдельный контрольный RESET на железе в этом этапе не проверялось. Новый моторный пуск не выполнялся, стабильность FOC на 5 секунд не подтверждена.

Порог 1,35 А, допуск UPDATE 2048, предел оценки 2 мс, бюджет 5312 тактов и критерии автонуля не менялись. После установки обе платы остаются на USB ПК, J1 выключен, 15 В включены по подтверждению пользователя. Для этого этапа переключать питание больше не требуется.

Полное свидетельство — `report.json`; исходные статусы, независимое чтение Flash/RAM и журнал — в `post_install_readback_r1`. Старый `REPORT_RU.md` в корне пакета описывает подготовку до записи; текущий статус установки находится здесь и в `manifest.json`.
