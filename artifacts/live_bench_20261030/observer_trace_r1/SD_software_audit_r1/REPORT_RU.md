# Проверка программной передачи SD без пуска

По просьбе пользователя повторные измерения питания не запрашиваются.

Три свежих ответа: SD LOW, SAFE/PWM=0, шина 10 В, ошибки UART и целостности 0. Возраст данных 8/17/33 мс. Установленный код получает уровень напрямую из GPIOA IDR PA6. Проверка конфигурации подтверждает режим AF6, pull-up и BKBID=0. Декодер установленного веб-сервера проверен для всех 256 комбинаций флагов; уровни свежих ответов совпадают с исходным флагом. Подмена сохранённой маски аварии в офлайн-проверке не меняет уровень SD.

Между предыдущим чтением и этими ответами изменился Linux boot ID, а native tick уменьшился. Непрерывность загрузки не подтверждается; никакие RESET или команды движения в этой проверке не отправлялись. Причина перезапуска не установлена.

Программная путаница между сохранённой аварией и текущим входом в проверенном пути не обнаружена. Физический источник LOW этим не определён: нельзя утверждать ни неисправность IPM, ни просадку питания. START/CLEAR/ARM/RESET/прошивка не выполнялись, защиты и старые записи не изменялись.
