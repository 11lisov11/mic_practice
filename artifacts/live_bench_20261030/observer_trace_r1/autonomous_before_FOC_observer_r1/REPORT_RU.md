# Автономная готовность к первому захвату наблюдателя

Пользователь подтвердил: обе платы на повербанках, ПК и Saleae отключены, 15В включены, J1 выключен, START/RESET не нажимал. Первый HTTP-запрос не успел до завершения сетевой загрузки; следующий ответ и SSH получены без переподключений и перезапусков служб.

Свежая пара3015/3016: SAFE/PWM0, run_id/start/HVarm/estop0, около10В. Автоноль готов, активная и сохранённая маски аварий0/0. SDHIGH, BreakIRQ включён, захват свободен; захват АЦП и новый регистратор наблюдателя свободны, complete/good/bad0. Проверены профиль128/CRC1354279011 и OFF64, first_fault отсутствует. CRC/последовательность/UART/транспорт/RPC без ошибок. Boot-record проверен по CRC, идентификаторы загрузки стабильны в серии проверки.

Выполнена только штатная stopped-конфигурация `SET ALGORITHM FOC` через `/api/algorithm`, затем подтверждены selected/requested2. Восемь статусов проверены. START/CLEAR/ARM/RESET/перепрошивка —0. Все226 исходных файлов установленного пакета совпадают с SHA256.

Подготовлен `tools/run_foc_observer_trace_trial.py`: использует прежний пятисекундный runner с теми же проверками и keepalive, меняет только ожидаемую пару3015/3016. До START дополнительно требует пустой OD/ADC-регистратор. После штатного STOP считывает новый1696байтовый observer_trace через GET, проверяет ABI/fw/CRC, неизменность boot и декодирует first_loss. Если оценка ни разу не стала достоверной, это отражается valid_samples0; отсутствие first_loss само по себе не доказывает нормальную оценку. Неполная/испорченная запись не объявляется успешным опытом и не вызывает повторный START. Проверки на сохранённом модельном захвате и повреждениях прошли, моторных команд от сборщика0.

Сейчас запрошен только J1 через soft-start, без других переключений и START/RESET. Подтверждение J1 ещё ожидается.
