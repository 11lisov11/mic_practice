# SD без подключения STEVAL

31.10.2026. Пользователь подтвердил: J1 и J4 выключены, шлейф снят со стороны STEVAL и остаётся на IHM09M2, платы на повербанках, RESET не нажимал.

Восемь свежих ответов подтверждают PA6 LOW при SAFE/PWM=0, корректной конфигурации входа и отсутствии ошибок UART/целостности. LOW сохраняется без STEVAL. Это локализует текущую проблему на оставшуюся сторону: шлейф, IHM09M2, Nucleo или подключённые к ним элементы. Это не доказывает причину каждого старого силового события и не доказывает исправность/неисправность IPM вообще.

Сначала сервер ответил timeout/503. SSH показал свежую загрузку Linux (uptime менее минуты). Последующие GET восстановились самостоятельно, без перезапуска служб или контроллеров с нашей стороны. Непрерывность с предыдущей загрузкой не заявляется. Во время восьми успешных чтений firmware3015/3016 и Linux boot ID стабильны.

Дальше запрошено снять другой конец того же шлейфа с IHM09M2, сохранив сам переходник на Nucleo. Только чтение PA6, без пуска. Питание J1/J4 остаётся выключенным. Пороги защит и код не менялись, старые записи не изменены.
