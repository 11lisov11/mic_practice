START. Uno MCU остановила привод по лимиту **5000 мс**, run_reason=1,

617,229 мкс; CPU upper bound 223,465 мкс. Это разные интервалы/максимумы,
их нельзя складывать как один синхронный снимок.

Все девять IRQ-счётчиков последнего завершённого окна достоверны.
