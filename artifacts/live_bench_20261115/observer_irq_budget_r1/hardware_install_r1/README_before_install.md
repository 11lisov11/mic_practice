# 2026111501 / 2026111502 — кандидат исправления задержек FOC

Образы собраны и проверены на ПК. На платы не записаны; пусков, CLEAR,
ARM, RESET и команд программирования при подготовке не было.

## Что установлено по записи

В единственном пуске установленной пары 2026111407/1408 привод остановился
через155мс. Первый отказ — FT_ESTIMATE_AGE:2028,44мкс при пределе2000мкс,
наблюдатель ещё в compute. Предыдущий шаг занял874,86мкс, из них не менее
769,32мкс внутри IRQ и не более105,54мкс вне измеренных тел обработчиков.
Новых Break, ошибок UART и перезапусков не было. Это не доказательство
нормального тока во всех кадрах: сырой ADC-рекордер полностью не получен.

В старом захвате нет отдельных времён TIM1/ADC/UART/SysTick. Называть один
из них доказанным источником всех769мкс нельзя. TIM1 UPDATE и ADC1/2 идут
на16кГц; дополнительные UART IRQ приходят пакетами. Отдельно найден и
воспроизведён дефект TX: UART TCIE включалось до конца DMA, а ранний TC
оставался активным при возврате из ISR. Его фактическое возникновение в
том пуске запись не подтверждает — соответствующего счётчика не было.

## Исправления

* DMA transfer-complete включает UART TCIE только после последней передачи
  памяти в UART. Пакет завершается лишь после последнего стоп-бита UART.
  Задержанный DMA IRQ, уже установленный финальный TC и ошибка DMA проверены.
  Ранний TC маскирует только TCIE и не очищает потенциально финальный флаг.
* Расчётный профиль контроллера специализируется на тех же константах после
  прежней проверки точного совпадения модели в каждом кадре. Это позволяет
  компилятору сворачивать повторные операции с параметрами двигателя.
  Из участка намагничивания убран расчёт скорости, результат которого
  раньше безусловно заменялся нулём. Активная петля скорости сохраняется.
* Наблюдатель повторно использует144байта уже ненужного Якобиана под
  ковариацию. Порядок арифметики не меняется. По ARM .su стек ma_observe
  уменьшился с880 до744байт; это статическая оценка функции, не измерение
  максимума всего вложенного стека на MCU.
* Записываются счётчики и inclusive-времена девяти реальных векторов в окне
  наблюдателя/первого отказа. Вложенные интервалы перекрываются: складывать
  их как загрузку CPU нельзя. Незавершённый ISR ещё не вошёл в счётчик.
  Прерванное обновление помечается недостоверным, без ожидания внутри IRQ.
  Вызов чужого IRQ-handler как обычной C-функции не считается вторым IRQ.
* Расширен OFF-only протокол timing: формат3,9страниц,63слова. CRC,
  идентификатор прошивки и свежесть сохраняются; старый формат отклоняется.
  Первый Break и первый отказ остаются отдельными неизменяемыми записями.

## Проверки

200000 побитных сравнений регулятора,20000 наблюдателя;1024 сценария
реальных извлечённых UART/DMA обработчиков; вложенные IRQ, early-return,
неполный snapshot, CRC/peer/format и все9страниц. Обе сборки успешны,
проверка динамического загрузчика Uno пройдена. Отдельные отчёты находятся
в verification, model_verification и build/uno.

Семь сценариев независимой модели дают прежние результаты. При внесённой
задержке2,1мс сохраняется MA_STALE; при сильном ADC-шуме сохраняется потеря
достоверности NIS. У модели задано время выполнения: она не измеряет новый
код на Cortex-M и не подтверждает выдержку5сек на физическом двигателе.

Порог1,35А, ADC2048тактов, возраст ADC187,5мкс, возраст оценки2мс,
runtime5312тактов, OFF4000тактов, настройки NIS,16кГц, watchdog, Break,
приоритеты и разрешения NVIC сохранены. Новая стоимость IRQ-инструментации
должна быть проверена на MCU перед следующим силовым испытанием.
