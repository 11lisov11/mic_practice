# Один CLEAR выполнен, FOC не запускался

Пользователь разрешил ровно один CLEAR и пуск только при готовых защитах.
RPC preflight пройден, исторические response12/send0 стабильны. Выбран FOC2.
После одной CLEAR-команды защита не восстановилась за контрольное окно:
MC current/saved mask4, mc/bp_fault5, SD HIGH, BIE=false. Шина321–322В.
Скрипт запретил START, не делал повторного CLEAR. START/ARM/RESET/flash=0.

Причина в отчёте: One CLEAR did not restore protections; no retry.
Это не неудачный FOC-пуск: ШИМ не включался, run_id0, захват АЦП при NIS
не проверен. UART/RPC новых ошибок не зарегистрировали. mc_clear_pending0
не доказывает успешное восстановление защиты; сохранённый reason8 сам по
себе не устанавливает, на какой именно проверке восстановления был отказ.

Boot audit пройден. Прежний SD63,4мкс побайтно совпадает до/после CLEAR
и с предшествующей записью. 3562 старых файла и162 release sources целы,
подробности в preservation_review.json. Защиты/пороги не менялись.
Повторный CLEAR/пуск не выполнялся. Требуется разбор восстановления Break/
MCSDK по сохранённым данным; текущий результат не разрешает новый запуск.
