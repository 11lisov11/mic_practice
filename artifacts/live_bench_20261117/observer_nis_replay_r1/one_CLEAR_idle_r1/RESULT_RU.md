# Выполнен один CLEAR без пуска

Единственная разрешённая команда доставлена и подтверждена диагностикой Nucleo.
START/ARM/RESET/перепрошивок не было. Шина до/после0В, SAFE/PWM0/HVarm0.
Новых RPC/UART ошибок за окно наблюдения нет; RPC-счётчики не перебазировались.

До команды сохранён первый SD-снимок. Сигнал уже HIGH, но BIE был выключен
после зарегистрированного события. Для штатного CLEAR это ожидаемый предмет
восстановления; для START такое состояние не допускается. Повреждённая запись,
SD LOW и неверная аппаратная конфигурация не допускают CLEAR-скрипт.
После команды BIE восстановлено, SD HIGH, аппаратный BKE включён, MOE0. Первый
снимок сохранён побитно;5664 предыдущих файла проверены по хешам.

Полного восстановления НЕ получено: MCSDK отказал в подтверждении аварии из-за
текущей низкой шины. Диагностика попытки: current4/occurred1028, result4
MCSDK_ACK_REJECTED. К концу живые маскиMCSDK0/0, но локальная ошибка5 и прежняя
транспортная защёлка7 остались. Повторный CLEAR не отправлялся и не разрешён.
Нельзя объявлять привод готовым к пуску при0В или считать защёлку снятой.

Готовность NIS проверена прямым пассивным чтением RAM через ST-LINK без halt/reset:
2052Б od_capture, total0, frozen0, sealed0, seen_valid0, replay_latched0,
456Б replay-полезной нагрузки нулевые. Захват свободен. Автонольready.
Это подтверждает свободную память, не наличие физического NIS-отказа.
Подробности: result.json, operation/report.json, recorder_check/report.json.
