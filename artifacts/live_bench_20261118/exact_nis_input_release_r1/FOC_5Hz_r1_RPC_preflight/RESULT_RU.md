# Разрешённый прогон не начат: RPC потеряна до первого CLEAR

Пользователь разрешил один CLEAR и один FOC5Гц/5000мс только после восстановления всех защит. Runner остановился в GET-only RPC-preflight с HTTP503/no response. Каталог моторного прогона FOC_5Hz_r1 не создан; CLEAR/START/ARM/команд конфигурации=0. Разрешённый один CLEAR и один START не израсходованы, но перед их будущим выполнением обязательна новая свежая проверка состояния.

Это не отказ FOC под ШИМ: двигатель не запускался. В исходной проверке до запроса RPC было всё ещё SAFE/PWM0/HVarm0, но Break защёлкнут; никаких команд, которые могли разрешить вращение, этот запуск скрипта не отправлял.

## Попытки восстановления без перепрошивки

Состояние службы/процессов сохранено по SSH. Прямой RPC get также не отвечал. Сняты 786432 байта RAM Uno пассивным OpenOCD без reset/halt/write. Дамп не атомарный. SSH ожидал 30 секунд и завершился по тайм-ауту, сам удалённый процесс продолжил чтение и закончил его; повторный OpenOCD не запускался. Полный файл затем скачан и проверен по размеру/SHA. Отдельного подтверждения состояния ядра после дампа нет: лог завершения SSH потерян, это ограничение отражено в recovery_actions.json.

Выполнено одно переподключение Linux-router /dev/ttyHS1 (close/open), без моторных команд и сбросов MCU. RPC временно восстановилась, ответы подтвердили прежние SAFE/PWM0/шину322В/transport0, но в следующем окне наблюдения снова возник HTTP503. Счётчик RPC к тому времени93/0; это не объявляется успешной квалификацией. Один перезапуск собственного процесса HMI тоже не восстановил устойчивую связь (сначала краткий connection refused при рестарте, затем HTTP503). Повторных перезапусков/переподключений и перепрошивок не выполнялось.

RAM разобрана на ПК с точным ELF1801 и штатным ELF ядра. В сохранённом состоянии таймер прогона не активен, mutex управления свободен, кольцевой буфер декодера пуст; outgoing mutex удерживается bridge_service_worker. Так как чтение не атомарное и занимает десятки секунд, эти признаки не доказывают deadlock и не устанавливают физическую первопричину RPC. Без доказательств параметры, защиты и ПО на платах не менялись.

Запрошено действие пользователя: выключить только J1, оставить15В/повербанки/проводку/RESET как есть. До подтверждения J1OFF дальнейшая аппаратная диагностика и пуск не выполняются. Перезапуск/перепрошивка Nucleo не нужны для сохранения текущего захвата.
