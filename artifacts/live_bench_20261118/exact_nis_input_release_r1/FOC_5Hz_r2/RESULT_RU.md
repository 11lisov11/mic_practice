# FOC1801/1802: 5 Гц / 5000 мс завершены; точный источник первого NIS захвачен

После свежего подтверждения J1ON выполнены ровно один CLEAR, один ARM и один START. CLEAR полностью восстановил MCSDK и Break; после этого старт разрешили штатные проверки. Основной прогон завершён Uno-автостопом ровно5000мс, затем отправлен штатный finalSTOP. native_done=false: первым сработал таймер Uno. Прошивок и сбросов не было.

Пользователь попросил ещё два визуальных повтора. Каждый выполнен отдельной командой START, 5Гц/5000мс, без CLEAR и сбросов, с тем же доказательством OFF64 текущего boot и всеми свежими live-guards. run_id1/2/3 завершились автостопом5000мс. Последний, третий пуск оператор подтвердил: «Да, вращался ровно». Вращение первых двух отдельно не подтверждено; их записи не переписывались. Визуальные повторы сохранили исходные NIS/ADC/SD побайтно, новых сырых снимков не выдаём за новые.

Физическое восстановление средних токов/напряжения из этих строк пока отдельно не вычислялось; готовность исходных данных не подменяет этот следующий анализ.
