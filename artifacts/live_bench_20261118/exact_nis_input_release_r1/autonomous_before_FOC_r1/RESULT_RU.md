# Автономная проверка перед FOC пройдена, без пуска и CLEAR

Пользователь подтвердил: обе платы на повербанках, USB ПК и Saleae отключены, 15 В включены, J1 выключен, Пуск/RESET не нажимались. Проверка выполнялась только HTTP GET, без SWD/прошивки/сбросов/конфигурации/CLEAR/START/ARM.

Первый TCP/HTTP-запрос не успел подключиться: initial_error.json сохранён. Затем обе службы стали доступны без вмешательства в питание или сервисы. Обнаружены Uno2026111801 / Nucleo2026111802 и новый сеанс после смены источника питания. Во время основной проверки boot не менялся.

20 свежих статусов, окно 21,125 с: приняты ещё 419 кадров, брака 0, UART-флаги 0, transport=0. RPC response/send timeouts=12/0 неизменны во всём окне; они сохранены как исторический baseline, новые тайм-ауты не допускаются. Причина этих 12 прежних событий этой проверкой не установлена.

Автоноль ready, 3 устойчивых блока, попыток 3; offsets2068/2065/2066/2068, spans20/37/27/28. Обычная токовая телеметрия свежая. SD HIGH, Break IRQ включено, конфигурация корректна, захват SD работает; нового записанного Break нет.

NIS и ADC receiver: записи не получены, complete/good/bad=0, rawhex отсутствует, run_id0. Установленный проверенный образ содержит схему NIS5/ADC3, 60 строк кольца, исходные16 плюс25 строк истории напряжения. Ранее пустые RAM-буферы были проверены на ПК; в этом новом автономном сеансе готовность свободных буферов выведена из загрузки/run_id0/телеметрии, прямого чтения RAM не было. Полнота будущего захвата под ШИМ пока не испытана.

На новом сеансе OFF64/64 PASS, fast3804/4000, timingfault0, profilererrors0. Предел возраста оценки2мс и все защиты неизменны. Это остановленная синтетическая CPU-проверка, не измерение под ШИМ.

SAFE/PWM0/HVarm0, шина по телеметрии9В. Маски MCSDK4/4 соответствуют MC_UNDER_VOLT при намеренно выключенном J1. Готовность к моторному START не подтверждена; дальнейший этап — только включение J1 пользователем через soft-start и новая проверка шины/SD/защит. Автоматического CLEAR или пуска не было.

Результаты: qualification/report.json, final_status.json, status_samples.jsonl и снимки SD. Старые файлы проверены по SHA, дополнительные свидетельства установки/CLEAR также сохранены и проверены отдельно.
