# Шина включена, START заблокирован сохранёнными защитами

Пользователь ответил «готво» после просьбы включить только J1 через soft-start. Проверено только GET: START/CLEAR/ARM/RESET/flash/SWD=0. Платы остаются на повербанках, USB ПК/Saleae отключены, 15 В включены.

20 статусов / 22,422 с: шина322–323В, свежие кадры (+445), брака0, transport0, UARTflags0. Исторические RPC12/0 не растут, boot стабилен, автоноль готов, буферы NIS/ADC свободны по телеметрии, fast3804/4000. Предел2мс и защиты не изменены.

До START, при MOE0, зафиксирован первый Break на PA6: полный LOW319отсчётов ×0,2мкс =63,8мкс, eventtick155722. SD сейчас HIGH, но BIE и первичный захват ещё не восстановлены. Маски MCSDK current/occurred4/4 (MC_UNDER_VOLT), fault5. Строгая проверка закономерно failed: no_fault_latches=false и SD_break_IRQ_ready=false. Пуск не отправлен.

Снимок сохранён в SD_first_before_CLEAR.bin, decoded_SD_wave.json, SD_trace.json и SD_snapshots.json. Кадр с PA4HIGH не является независимым измерением TP23: перемычка TP23→PA4 ранее снята. Причина импульса на PA6 этим чтением не установлена.

Пределы4000/2мс, исходный ток1,35А и остальные защиты сохранены. Готов и офлайн проверен runner1801/1802 tools/run_exact_nis_input_FOC_trial.py; --verify-package-only аппаратных команд не посылает. Реальный запуск возможен только после отдельно разрешённого штатного CLEAR и подтверждения восстановления всех защит. Предыдущий один CLEAR был израсходован в сеансе USB до смены питания. В новом автономном сеансе CLEAR не выполнялся.
