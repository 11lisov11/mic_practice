Пользователь подтвердил J1 выключен, платы на ПК;15В и проводка не менялись.
До записи свежие GET/SWD подтвердили шину около10В, MOE0 и BKE1. Оба MCU
записаны по одному разу. Uno после записи оставалась HALTED до обновленияNucleo;
затем отдельная readback-проверка Uno запустила новую согласованную пару.
У Nucleo полное независимое чтение120416байт совпало с ожидаемым HEX-образом
(четыре пропущенных байта заполненыFF, как и положено при записиHEX).
OpenOCD отдельно сверил загрузчик и полный образ Uno; лог verify_uno.log содержит
«UNO Q verification PASSED». Калибровка до/после совпадает. Matching HMI установлен
с резервной копией прежних файлов; один перезапуск собственной службы.

## UART921600 — FAIL

Фактический USART1 Nucleo: Init.BaudRate921600, BRR184, CR1=0x2d, FIFOEN0.
Новая пара1803/1804 передаёт свежие ответы, но ошибки продолжают расти:
в трёх последовательных GET mc_bad_integrity16→17→18, Uno hardwareerrors94→97→98,
softwareRXdropped0. Nucleo last UART flags8 — ORE; локальный заголовок Zephyr
определяет Uno UART_ERROR_OVERRUN как1, именно этот бит установлен.
Это аппаратные потери до программного буфера. Защёлка transport4 сохранена;
CLEAR/сброс счётчиков/подмена критерия качества не применялись.

Отдельные пассивные IRQ-замеры: ADC1_2 в среднем7,52мкс, USART1≈1,42мкс;
интервал UART-символа9216008N1 —10,85мкс. Приоритет ADC вышеUART, FIFO Nucleo
отключён. Эти данные указывают на недостаточный запас обслуживания RX при новой
скорости; конкретный максимум задержки IRQ и состояние FIFO Uno не измерены,
поэтому не объявляется доказанной единственная точная причина задержки.
Следующий предмет исправления — аппаратный путь приёма/буферизация UART,
с сохранением детекции ошибок и приоритетов моторных защит. Рабочей связь не объявлена.

Установщик завершился passedfalse на «UART unhealthy». Дополнительный OFF-верификатор
сделал независимый readback и измерениеCPU; для этого его prerequisite заменён

калибровку. Все проверки качестваUART оставлены строгими и не пройдены; это
разделение результатов, не обход защиты. Подробности в post_install_idle_r1/report.json.
