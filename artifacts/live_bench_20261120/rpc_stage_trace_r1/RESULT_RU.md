# Uno2026112011: диагностический журнал стадий RPC

Собрано,156 PC cases PASS,LLEXT PASS. Не установлено. Nucleo1810 без изменений.
Образ в release/, SHA и контракт в release_manifest.json. Это захват причины
пропуска ответа, не подтверждённое исправление. Моторные защиты/тайм-ауты прежние.

Пакет добавляет только журнал128*32+16=4112B, без новых методов RPC/пакетов,
периодических логов и изменения расписания. На Uno используется короткий
irq_lock для согласованной записи8 слов; Nucleo и его IRQ/математика не меняются.
Журнал читается по SWD по символу mic_rpc_trace с привязкой к этому ELF.
Слоты имеют sequence и XOR guard; RAM читается неатомарно, повреждённые/
изменившиеся слоты следует отклонять. Результат чтения никогда не разрешает пуск.

Полный разбор предыдущего прогона и RPC в соседнем RESULT_RPC_DIAGNOSIS_RU.md.
Новые START/CLEAR/ARM/RESET/flash=0. Сохранённые файлы прогона сверены по SHA.


## Установка и проверка 2026-11-20

Диагностический образ записан и побайтно сверён по полному чтению Flash.
Nucleo 1810 совпала с прежним образом. Обновлён веб-сервер под новую пару.
Исходная калибровка и 21 файл прошлого прогона совпали по SHA-256.
Один переходный HTTP 503 сменился 45 успешными чтениями за 57,6 секунды.
Ошибки UART и новые тайм-ауты RPC за эту проверку отсутствуют.
Журнал из RAM содержит семь полных цепочек GET с результатом отправки.
При этой проверке ШИМ выключен. Причина сбоя на более тяжёлом статусе не установлена.


## Дополнительная проверка RPC при выключенном J1

Три параллельных клиента выполнили 210 запросов статуса за 74 секунды.
Максимум 719 мс. Ошибки UART и тайм-ауты RPC не появились. Из RAM Uno
пассивно считан журнал по USB и Wi-Fi. В обоих случаях контрольные слова
подтвердили 118 совпадающих слотов. Команд двигателю не отправляли.

В трёх прежних записях последний полученный ответ перед пропуском
следующего GET занимал 14 336 байт на проводе. В отдельной записи GET
после ответа того же размера успешно завершился. Размер сам по себе
не объясняет отказ. При текущем опросе ответы около 8,3 КБ, а массивы
АЦП и наблюдателя в живом статусе отсутствуют. Сохранённые массивы
предыдущего прогона остались в архиве.
