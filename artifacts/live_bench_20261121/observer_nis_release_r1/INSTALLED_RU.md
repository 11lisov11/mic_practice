# Uno Q 2026112101 и Nucleo 2026112102 записаны

Каждая плата прошита один раз. Образ Uno Q проверен отдельным проходом верификации флеша. Два чтения флеша Nucleo по 121 752 байта совпали с ожидаемым образом. Калибровка DC-шины идентична по SHA-256, 567 архивных файлов повторно сверены. До записи шина составляла около 10 В по телеметрии и прямому чтению Nucleo. J1 оставался выключенным. [Запись и верификация](hardware_install_r1/report.json)

Два снимка Nucleo подтвердили 64 расчётных случая без ШИМ, максимум быстрого расчёта **3810 из 4000 тактов**. Счётчик расчёта наблюдателя показал 25 788 тактов, максимум времени наблюдателя по профилировщику 239,08 мкс. Ошибок профилировщика нет, `MOE=0`, `BKE=1`, `BIE=1`, `PA6=HIGH`. Порог NIS 25, предел возраста оценки 2 мс и остальные защиты сохранены. Команды START, ARM и CLEAR не отправлялись. [Прямой замер Nucleo](post_install_idle_r1/report.json)

Полная проверка UART остановилась на сохранённой защёлке FE. Первый отказ записан через 2178 мс после загрузки Nucleo до первого принятого кадра этого сеанса. За следующие 24 чтения статуса пришло 547 валидных ответов Nucleo, счётчики UART и RPC не выросли. SD HIGH, автоноль готов. Защёлка UART остаётся активной.
