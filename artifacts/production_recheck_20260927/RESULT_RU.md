# Повторная проверка стенда, 27.09.2026

## Результат

Рабочая прошивка UNO Q обновлена до **2026092702**, запись и чтение для проверки завершились успешно. Nucleo осталась на **2026091401**. Стенд оставлен в SAFE, VF, PWM=0, разрешение силового запуска снято. Высокое напряжение не подавалось.

## Исправления

1. При постоянной ошибке пониженного напряжения CLEAR раньше повторялся бесконечно. Nucleo при каждом CLEAR обнуляла счётчик ошибок приёма, что могло маскировать ошибки связи. Теперь завершение CLEAR подтверждается соответствующим ответом на конкретный запрос при выключенных выходах. Физическая ошибка напряжения сохраняется и продолжает блокировать запуск.
2. Проверка рабочего состояния теперь контролирует завершение CLEAR и изменение накопительных счётчиков ошибок, которые CLEAR не сбрасывает. Проверяются обе версии прошивок, конечный STOP, отсутствие разрешения запуска и корректность числовой телеметрии.
3. Утилита обновления по Wi-Fi теперь передаёт отдельный ключ управления для восстановительного CLEAR. Без него команда не отправляется; ключ прошивки не подставляется вместо ключа управления. Отсутствующие, отрицательные и нечисловые значения состояния больше не принимаются за исправный контроллер. Ошибка undervoltage по-прежнему не считается готовностью к работе двигателя.
4. Исправлены устаревшие тестовые данные STOP и тест номера сборки. Добавлены проверки отказа при неподтверждённом выключении выходов и отсутствующем ключе управления.

- Сбрасываемые счётчики ошибок на всём интервале равны нулю.
- Ожидаемая ошибка Nucleo: 5, undervoltage при отключённой шине.

- Физический Saleae, 24 Мвыб/с, фактическая запись 0,256 с: CH0-CH5 постоянно LOW, переходов нет. Это проверка выключенных выходов, не активного ШИМ.

## Пакет и ограничения

Обновлены `firmware/ready_to_flash` и ZIP. Проверены 30 артефактов. Отчёт выключенных выходов привязан к текущим образам по SHA-256. Проверка физической силовой части остаётся `hardware_validated=false`.

Предыдущие активные диагностические испытания находятся в `artifacts/wifi_transitions_20260927_r7`. Они проводились с диагностическими прошивками и не являются испытанием активного ШИМ текущего рабочего образа. Предыдущий длительный тест нулевых счётчиков недостаточен сам по себе из-за обнаруженного повторения CLEAR; настоящий отчёт дополнительно проверяет несбрасываемые счётчики.

Не подтверждены аппаратное отключение SD/BKIN, точное подключение CH6 и питание J4, калибровка измерений шины, испытание внешнего плавного пуска и соответствие реального двигателя конфигурации. Для SD/BKIN необходимо уточнить фактическую схему подключения; ответ «вроде да» не доказывает её. Разрешение на силовой запуск этим отчётом не выдаётся.
