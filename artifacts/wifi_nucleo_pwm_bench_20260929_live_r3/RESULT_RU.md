# Результат сетевого низковольтного теста ШИМ

Итог: **PASS**. Полные машинные результаты, команды и пути к захватам Saleae
сохранены в [report.json](report.json).

- Команды шли по локальному HTTP на Wi-Fi-адрес UNO Q `192.168.1.138:8080`
  через WSL NAT (VPN блокировал LAN для Windows). ADB не передавал команды
  управления; он использовался только для чтения токена перед тестом и для
  перепрошивки временного образа UNO Q.
- UNO Q передала команды по UART на Nucleo-G431RB. Диагностический backend
  выдал комплементарный ШИМ на всех шести линиях. Saleae измерил несущую
  около `10,02 кГц`, минимальный зазор между плечами `2,0 мкс` и нулевое
  перекрытие. `PA6/CH6` оставался LOW на всём интервале активного ШИМ.
- `STOP` выключил все линии. Прошли три непрерывных захвата START/STOP и все
  29 сценариев: повторные пуски, ESTOP, отказ запуска без ARM/ключа, неверная
  фраза ARM, ограничение времени и потеря heartbeat. Ожидаемые HTTP-отказы
  опасных команд учитываются как успешные проверки защиты.
- После теста **обе рабочие прошивки восстановлены** и проверены захватом:
  CH0–CH5 LOW, без фронтов. Повторное сетевое чтение: `SAFE`, `PWM=0`,
  `Vbus=0`, HV не вооружён, рабочие build ID UNO `2026092702`, Nucleo
  `2026091401`. Код `mc_fault=5` в этом режиме остаётся при нулевой шине.

Условия: силовой вход STEVAL J1 и двигатель отключены, J4 выключен,
34-контактный шлейф STEVAL J2 оставался подключённым. Это **тест логики и
линий управления на временных диагностических прошивках**. Он не подтверждает
работу силовых ключей IPM, аппаратное срабатывание SD/BKIN или запуск
производственного V/f под напряжением. Для них нужны отдельные испытания.

Первая попытка частично прошла, но дополнительные HTTP-клиенты обходили
WSL-маршрут. Во второй попытке сырой CH6 был HIGH только до первого фронта
PWM при всех шести LOW; во время PWM он был LOW. Анализатор теперь сохраняет
сырой факт и отдельно проверяет весь интервал переключений. Третья попытка,
ссылка выше, завершилась полностью успешно.
