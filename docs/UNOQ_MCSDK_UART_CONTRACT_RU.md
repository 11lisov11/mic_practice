# UNO Q - NUCLEO-G431RB: контракт UART для MCSDK ACIM V/F

Этот канал связывает UNO Q только с пользовательским адаптером официального проекта MCSDK. Он не является прямым управлением шестью PWM-входами IPM.

## Физическое соединение

Связь обязательна через двухканальный изолятор UART (например, ISO7721), `115200 8N1`:

| Направление | UNO Q | Изолятор | NUCLEO-G431RB |
|---|---|---|---|
| Команда в привод | `D1 / Serial1 TX` | вход канала A -> выход A | `PB7 / USART1_RX` |
| Ответ и телеметрия | `D0 / Serial1 RX` | выход канала B <- вход B | `PB6 / USART1_TX` |

Питание каждой стороны изолятора берётся от своей 3.3 V логики. Земли через изолятор не объединяются. Аппаратный E-stop и вход break IPM остаются отдельной проводной защитой, а не зависят от UART.

## Разрешённый кадр

Размер кадра 32 байта, XOR CRC по байтам `0..30` находится в байте `31`.

| Байты | Значение |
|---|---|
| `0..1` | `AA 55` |
| `2` | Версия `0x02` |
| `3` | `0x01` только для запуска; `0x08` только для чистого `CLEAR`; `0x02` E-stop |
| `4` | Для запуска только `MODE_SCALAR = 3`; для остановки/CLEAR `MODE_OFF = 0` |
| `5` | Sequence |
| `6..9` | Частота статора в milliHz, little-endian |
| `10..13` | Историческое поле амплитуды; MCSDK его не использует, V/F задаётся профилем двигателя |
| `14..30` | Только нули |
| `31` | XOR CRC |

`MODE_DUTY`, `MODE_FOC`, `MODE_VECTOR`, `DIAG`, ненулевые сервисные поля, неверный CRC/версия, частота вне текущего лимита профиля или тишина на линии более 300 мс вызывают `MC_StopMotor1()` и защёлкивают отказ. Снятие отказа возможно только чистым кадром `CLEAR` (`flags=0x08`, `mode=0`, все прочие поля нулевые).

Ответ возвращает тот же `sequence`, счётчики good/bad, статус link/fault/PWM и код отказа. Поля энкодера, токов, температуры и сервисных выходов в этом адаптере намеренно равны нулю: для них нужен отдельный согласованный формат телеметрии MCSDK, а не выдуманные значения.

## Сборка

Собрать обе прошивки и манифесты:

```powershell
powershell -ExecutionPolicy Bypass -File C:\mic_practice\tools\build_firmware_bundle.ps1
```

Перед сборкой команда автоматически проверяет версию, длину кадра, запрещённые режимы, поля сервиса, timeout и то, что адаптер Nucleo не трогает PWM напрямую. После сборки сверяются SHA-256, размеры и состав обоих комплектов. Это статическая проверка и тест векторов протокола; она не заменяет HIL-испытание.

Результаты:

- `mcsdk_reference/ACIM_IPM15B_SIEMENS_REFERENCE_NOT_AIR56/CubeIDE_V1.6.3/STM32CubeIDE/Debug` - Nucleo `ELF/BIN/HEX`.
- `firmware/unoq_mcsdk_scalar` - UNO Q `BIN/ELF/HEX`, готовый upload-пayload `UNOQ_MOTOR.ino.elf-zsk.bin` и манифест. Для текущего dynamic link mode прошивается именно файл `*.elf-zsk.bin`; обычный `*.bin` оставлен для анализа.

Это сборочный комплект для official Siemens reference. До внесения шильдика и измерений AIR-56 gate намеренно не позволяет назвать Nucleo-прошивку готовой для этого двигателя.
