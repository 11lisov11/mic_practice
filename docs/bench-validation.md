# Проверки стенда АИР56Б2

## Комплект 2111/2112

Идентификаторы сборок `2026112111` (Uno Q) и `2026112112` (Nucleo). Профиль I/f → FOC ограничен 5 Гц. Пороги NIS 25, 4000 тактов для проверки быстрого расчёта без ШИМ и 2 мс для возраста оценки сохранены. Токовый порог 1,35 А и лимит UPDATE 2048 тактов сохранены.

| Условия | Подтверждённый результат |
| --- | --- |
| ПК, регрессия MCSDK | В 12 сценариях OFF больше не перезаписывает подтверждение CLEAR в `FAULT_OVER`. STOP в RUN принимается. Активная авария блокирует ACK. |
| ПК, повтор записи шага 536 | 51 слово состояния и расчёта NIS совпали побитно с захватом. Это проверка воспроизведения записи. |
| Платы на USB, ШИМ выключен | Чтение обоих образов совпало. Калибровка сохранена. DWT: 64 проверки, максимум 3822 такта. |
| CLEAR при 9–10 В на DC-шине | UART-защёлка снялась. SD в HIGH, прерывание Break включено. MCSDK повторно зафиксировал низкое напряжение шины. Переход в `IDLE` при нормальной шине остаётся открытой проверкой. |
| Предпусковая проверка при сообщённом включении J1 | Телеметрия показывала 10 В, ШИМ был выключен. Команды CLEAR и START в этом сеансе не отправлялись. Позднее наблюдалась просадка БП J4 с 15 примерно до 2 В. Силовой тракт требует аппаратной диагностики. |

Предыдущие прогоны давали отдельные результаты для V/f и ранних вариантов FOC. Они относятся к своим версиям и условиям. Преимущество FOC, адаптивного ШИМ или ИИ на исправном нагруженном стенде остаётся предметом исследования.
