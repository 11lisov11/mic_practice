КОМПЛЕКТ ОБНОВЛЕНИЯ UART: UNO Q 2026100709 / NUCLEO 2026100710

Подготовлено и проверено программно. В этом задании платы НЕ прошивались.
Это рабочее скалярное V/f управление, не диагностическая прошивка с обходом защит.

ФАЙЛЫ ДЛЯ ЗАПИСИ
Nucleo G431RB: nucleo/ACIM-NUCLEOG431RB-IPM15B-VF_OL.hex через ST-Link.
UNO Q MCU: uno_q/UNOQ_MOTOR.ino.elf-zsk.bin через штатный загрузчик UNO Q.
Не заменять этот файл обычным UNOQ_MOTOR.ino.bin: это другой формат.
Uno Q 709 пересобран; если на плате уже точный образ 709, повторная запись не нужна.
Linux UNO Q: linux/web_hmi; сервер принимает пару 709/710, калибровка сохранена.
Не удалять существующие калибровку, ключ управления, настройки и журналы.

ИСПРАВЛЕНИЯ И ПРОВЕРКИ
Приём UART повторно проверяется перед обработкой команды, заданием рампы,
START и после него; проверяется ошибка при возобновлении прерывания USART1.
При ошибке команда отменяется, очередь очищается, STOP и защёлка сохраняют причину.
Сохранены предыдущие исправления рампы, таймаутов, STOP, диагностики, BKIN и матрицы.
NE/FE/ORE/PE не игнорируются; ADC/TIM защитные прерывания не маскируются.
Скорость 115200, протокол v2, V/f и измерительные преобразования не изменены.
DMA, CRC16 и смена скорости не включены как непроверенные гипотезы.
18 программных наборов пройдены; отчёты и контрольные суммы находятся в комплекте.

ГРАНИЦЫ ПРОВЕРКИ
Тесты выполнялись на ПК с моделью HAL/MCSDK, без выдачи команд стенду.
Измерения физического ШИМ, задержек защит и испытание под нагрузкой этим комплектом
не подтверждены. Причина UART_NE при силовом запуске пока не установлена.
Preflight сохраняет две незакрытые аппаратные проверки: soft-start и SD/BKIN.
Не выдаётся разрешение на подачу 220 В; установка требует последующей проверки.
Старый скрипт первого силового пуска не разрешает 710: его ограничения не ослаблялись.

ПОРЯДОК УСТАНОВКИ
При отключённом силовом вводе и разряженной шине записать Nucleo, проверить flash
сравнением с HEX, затем обновить HMI с сохранением пользовательских данных.
Инструмент install_vbus_hmi_fix_remote.py предназначен только для Linux UNO Q;
он проверяет SAFE, выключенный ШИМ и разряженную шину перед заменой сервера.
После установки проверить по Wi-Fi build IDs 709/710, SAFE, PWM=0, ARM=0,
свежесть телеметрии и сохранность калибровки. Автоматический START не выполняется.
Не подключать ПК/анализатор к неразвязанному стенду с силовым напряжением.

ПРОВЕРКА АРХИВА (БЕЗ ПОДКЛЮЧЕНИЯ ПЛАТ)
python tools/package_uart_guard_update.py --verify-archive <путь к ZIP>
Содержимое и manifest проверяются по SHA-256; это не цифровая подпись.
