WATCHDOG НА САМОЙ КРАСНОЙ BSMCE04U - БЕЗ ОТДЕЛЬНОЙ BLUE PILL

СТАТУС
Оригинальный дамп красной платы пока НЕ считан. До его получения, двух независимых
чтений и проверки копий запись этого кандидата ЗАПРЕЩЕНА по требованию пользователя.
Статус: hardware_backups/RNR_ECO_MOTION_816FAD79CE5/STATUS.json. Обязательные
правила резервного копирования закреплены в корневом AGENTS.md.
Подготовлен и собран кандидат для AT32F403RCT6 на официальном BSP Artery 2.1.3.
Фактическая маркировка сообщена приблизительно; модель МК не подтверждена точно.
Образ не записан, штатная прошивка сохранена в плате. Не является готовым образом
для произвольной красной платы, AT32F403A или STM32F103.

ПОЧЕМУ НУЖНА ЗАМЕНА ШТАТНОЙ ПРОШИВКИ
На нашей USB-плате A720:F803 / serial 816FAD79CE5 подтверждены включение/выключение
OUT1..4. После аварийного выхода управляющего процесса OUT1 сохранился более 5 с.
Это подтверждение маски firmware; напряжение на клеммах ещё не измерялось.
Таким образом, штатная прошивка не реализует нужный контроль пропадания команд.

ПРЕДПОЛАГАЕМАЯ КАРТА
PC6 -> OUT1: разрешение CZERO T3D, активный уровень HIGH предполагается.
PC7/8/9 -> OUT2/3/4: всегда LOW. PA8 AVI/PWM LOW, PB10 HIGH запрещает буфер STEP/DIR.
PC11 LOW подключает USB D+ через штатный ключ. Карта взята из проекта grblHAL
boards/mach3_bob_map.h и должна быть прозвонена именно на нашей ревизии.
Предположен внешний кварц 8 МГц; частота ядра 72 МГц, USB 48 МГц.
До идентификации и валидного heartbeat OUT1 выключен. Проверка выключенного
состояния во время сброса/BOOT/SWD/потери питания также обязательна физически.

ПРОТОКОЛ
USB CDC, демонстрационные VID/PID официального SDK Artery 2E3C:5740.
Serial формируется SDK из уникального ID чипа; после прошивки записывается
реальная USB-идентичность и COM в red_board.runtime_usb. Программа не угадывает порт.
HELLO: снимает разрешение, снимает защёлку протокола, отвечает
ID RNRWD_AT32F403RC_20261122 <CRC16>.
Q nonce: выдаётся раз в 125 мс. ACK nonce CRC: одноразовый ответ не старше 150 мс.
Только валидный ACK продлевает TTL 750 мс. Host отвечает после свежих измерений
и подтверждённой записи момента T3D. CRC - стандартный Modbus по ASCII телу.
STOP снимает OUT1 до ответа OFF 00000000 CRC. Timeout/STOP/ошибка защёлкивают
разрешение снятым до нового HELLO. При USB reset/suspend разрешение снимается.
Встроенный аппаратный watchdog ~501 мс по номинальным 40 кГц LICK. Он кормится
только при продвижении миллисекундного счётчика; зависание main/SysTick не должно
оставлять разрешение. Фактическое максимальное время измеряется на плате.

СБОРКА И ПРОВЕРКИ
python -X utf8 tools/build_red_board_watchdog.py
Используется уже установленный Arm GCC 12.3.1. BSP закреплён по commit и SHA-256.
Скрипт не открывает USB, не запускает программатор, не стирает память.
Нативный C++ тест компилирует ту же state machine: идентификация, boot OFF,
CRC, nonce, повтор/устаревание, защёлка timeout/STOP, новый HELLO, переполнение времени.

ПОРЯДОК УСТАНОВКИ
1. Красная плата отдельно, без внешних силовых цепей/двигателей. Уточнить полную
   маркировку МК; прочитать CPUID/device/project ID через SWD и сверить с Artery.
2. Проверить карту платы и кварц. Подключить подходящий программатор к фактическим
   SWDIO/SWCLK/GND/VREF 3.3 В и при необходимости NRST. Порядок площадок не угадывать.
3. Сначала только чтение защиты/flash/option bytes; сохранить оригинальный образ,
   параметры, ID и SHA-256. Резервная копия профиля Drufel не является копией firmware.
4. Если чтение защищено, остановиться перед снятием защиты: оно может стереть
   единственный оригинал. Рабочая прошивка пока не изменялась.
5. После подтверждения целевого МК/карты установить проверенный соответствующий
   образ и сравнить записанную flash с файлом. Эта запись в текущей задаче не выполнена.
6. Без нагрузки проверить USB CDC/ID, выход OUT1, его полярность, включение/сброс/
   watchdog, остановку host/потерю USB, питание и аппаратную цепь CZERO.
7. Заполнить red_board и qualification в config.local.json только по измерениям.
   После смены прошивки Drufel с этой платой не работает до восстановления оригинала.
