# АИР56B2: проект V/F по шильдику

Этот каталог является отдельным проектом для `IEK АИР56B2`, а не копией Siemens для прошивки. Физическое подключение двигателя: `220 В Delta`; звезда для этой шины не используется.

Паспортные данные, внесённые в `.ioc`:

- `0,25 кВт`, `50 Гц`, `2720 об/мин`, `1 пара полюсов`;
- `220/380 В Delta/Y`; выбрано `220 В Delta`;
- линейный ток `1,24 А`;
- `NOMINAL_PHASE_VOLTAGE=127 В`: эквивалентная phase-to-neutral величина MCSDK (`220 / sqrt(3)`), а не физическое переключение обмоток в звезду;
- `FLUX_K=0,5717009 В·с`: `127 * sqrt(2) / (2*pi*50)` для V/F; коэффициент пересчитан отдельно, так как Workbench сохраняет старое значение при ручной смене `Vn`;
- максимальная команда ограничена `3000 об/мин`, то есть ровно `50 Гц` для одной пары полюсов. Это синхронная частота поля V/F; паспортные `2720 об/мин` остаются номинальной механической скоростью ротора под нагрузкой. Старт только по валидной UART-команде, по умолчанию V/F target `500 об/мин`.

Конфигурация предназначена для `ACIM V/F Open Loop` на `NUCLEO-G431RB + X-NUCLEO-IHM09M2 + STEVAL-IPM15B`. Параметры `Rs`, `Rr`, `Lls`, `Llr`, `Lm` и инерция не определяются из шильдика. Они намеренно не объявлены параметрами АИР56B2 и должны быть измерены до FOC, автоидентификации или допуска к силовому испытанию.

Этот каталог не разрешён для подачи 310 В DC: не реализована привязка управляющего выхода Nucleo к узлу precharge, нет HIL-проверки цепи fault/E-stop и нет измеренного эквивалента двигателя. Проверка `mcsdk_release_preflight.py` обязана блокировать выпуск до устранения этих условий.
