# Управление измерениями по их энергетической ценности

## Назначение и границы

Исследуется верхний уровень адаптации возбуждения асинхронного двигателя.
Штатный параметризованный FOC сохраняется. Супервизор получает только текущие
измерения мощности, токов, напряжения, скорости энкодера и задание скорости;
истинные параметры и внутренние состояния объекта ему не передаются.
Следовательно, это адаптация по данным поверх FOC, не полностью безмодельный
привод, не нейросетевой регулятор и не решение проблемы наблюдаемости при нуле.

Проверяемая гипотеза: выбор измерения по ожидаемому полезному энергетическому
эффекту за остаток рабочего интервала предпочтительнее выбора только по
снижению неопределённости. Сам принцип value of information / knowledge gradient
известен: [Frazier, Powell, Dayanik, 2008](https://optimallearning.princeton.edu/Papers/FrazierPowellDayanik_KnowledgeGradientSICON.pdf),
[Frazier, Powell, 2008, правило остановки](https://www.informs-sim.org/wsc08papers/035.pdf).
Наша цифровая проверка касается переноса такого критерия на физически исполняемые
пробы с переходами, проверкой кандидата и восстановлением. Новизна этого переноса
не считается установленной без сопоставления с близкими работами и конкурентами.

## Наблюдаемая проба

Исходное задание тока возбуждения A равно 0,83 А. Набор кандидатов:
0,65; 1,00; 0,74; 0,915 А. Не более двух проб, скорость изменения задания 1,5 А/с.
Каждое наблюдение выполняется по последовательности A -> B -> A, с проверкой
установления доступных сигналов и сбором окна на каждой стадии. Это не мгновенное
измерение статической функции: время и энергия переходов учитываются объектом.

В момент центра окна B опорная мощность оценивается линейной интерполяцией
между средними мощностями двух окон A. Контраст g равен опорной мощности минус
мощность в B. Интерполяция устраняет аффинный общий дрейф при выполнении этой
гипотезы, но не гарантирует устранение скачка нагрузки или скрытого перехода потока.
Используемая ширина ошибки является эвристической, не доверительным интервалом.

Для отбора формы отклика используются 225 локальных вогнутых квадратичных
гипотез. Они не объявляются паспортными параметрами двигателя. Несовместимость
наблюдений с набором приводит к отказу и возврату, а не к расширению набора
по истинным параметрам цифрового объекта.

## Критерий в джоулях

Пусть t - время решения, T - заранее заданный конец рабочего интервала,
M - уже измеренные кандидаты, S+ - накопленная оценка положительного перерасхода
законченных проб. Для кандидата j резервируются времена проверки и возврата:

```text
H_j(t) = T - t - tau_verify(j) - tau_return(j)
U_j(t) = g_lower(j) * H_j(t) - C_verify_return(j)
V_now  = max(0, max U_j(t) по допустимым j из M)
```

Допустимость включает H > 0, g_lower >= 2 Вт, S+ + C <= 8 Дж и
U_j - S+ > 0,1 Дж. В этой записи 8 Дж ограничивают прогноз, не доказанный
физический перерасход. Исторические затраты сохраняются в проверке окупаемости,
но не вычитаются повторно только из одной ветви сравнения будущих действий.

Ценность следующей пробы q оценивается одношаговым просмотром вперёд:

```text
Q_q = sum_y weight(y) * [-C_ABA(q,y) + V_after(y, t + tau_ABA(q))]
tau_ABA(q) = tau_stage(q) + tau_return(q)
```

В каждой наблюдаемой ветви y допустим только уже измеренный кандидат либо
сама завершённая q. Максимум по неизвестной истинной гипотезе не используется.
Одинаковые интервалы наблюдаемого выигрыша объединяются до выбора действия.
Цена пробы оплачивается даже в ветви, где дальнейшее принятие невозможно.

Неизвестная цена пробы представлена рабочими долями 0,25/0,5/1 от текущего
прогноза с равными весами. После гипотетического наблюдения применяется полный
штатный прогноз следующего перехода по этой новой истории. Повторного снижения
известной цены на ту же долю нет. Эти веса не являются калиброванными
вероятностями; успешность свежей проверки в прогнозе предполагается, но в
исполнении проверяется заново. Поэтому Q - энергетический суррогат, не теорема
о математическом ожидании фактической экономии.

Если лучший измеренный кандидат выгоднее следующей пробы, выполняется его
свежая проверка. Если выгоднее проба, выполняется только она. Если обе ветви
не имеют положительной ценности, сохраняется A. Ограничения по току,
напряжению, смене режима и плановому возврату продолжают действовать.

## Независимый энергетический контроль

В цифровом объекте проверяется баланс:

```text
E_input = W_shaft + E_stator_copper + E_rotor_copper + E_core + E_friction + delta_E_stored
E_loss  = E_stator_copper + E_rotor_copper + E_core + E_friction
```

В паре опытов экономия входной энергии равна сумме различий работы вала,
потерь и изменения запасённой энергии. Поэтому основной результат - разность
E_loss за полное одинаковое время, включая все пробы, отказы и общую секунду
восстановления. Меньшая работа или незавершённое восстановление не выдаются
за полезную экономию. Состояния сравниваются с учётом общей симметрии
электрического угла; допуски заданы в протоколе до независимых расчётов.

## Что может подтвердить эксперимент

- Положительная экономия против постоянного возбуждения: полезность адаптации
  в конкретной матрице режимов при сохранении пригодности сравнения.
- Преимущество против first-good обоих порядков и с тем же меню: вклад выбора
  момента измерения/принятия, а не только удачного порядка или раннего принятия.
- Преимущество против прежнего охраняемого аналитического поиска: практическая
  ценность усложнения относительно сильного конкурента.
- Сохранение результата при уменьшении шага: проверка численной устойчивости,
  не верификация самого двигателя или преобразователя.

Протокол, матрица, полные случаи, контрольная сумма исходников и причины отказов
хранятся рядом с результатами. Вариации насыщения одного F1 не увеличивают число
независимых двигателей. Итоговые числа берутся из сгенерированного RESULTS_RU.md,
а не из этой методической записки. Заявлений об аппаратном испытании здесь нет.
