                                STM32 MCSDK – Tools – ST MC Workbench




Introduction
The STM32 Motor Control Software Development Kit (MC SDK), is part of the STMicroelectronics motor-
control ecosystem. It includes:
  • ST MC FOC FW library for Permanent-Magnet Synchronous Motor (PMSM) field-oriented control
      (FOC)
  • ST MC 6 Step FW Library
  • ST Motor Profiler
  • ST Motor Pilot
  • ST MC Workbench software tool, a Graphical User Interface (GUI) for the configuration of MC SDK
      firmware library parameters

This User’s Manual explains How To use the ST MC Workbench software tool included with this MC SDK.

   1. General information
The ST MC Workbench software tool provides an easy and friendly way to configure your MC application
based on your hardware setup.
After the configuration, the user can generate the project file and use it together with STM32CubeMX
software for further application extension.

The ST MC Workbench runs on PC systems using Windows® OS, requiring a USB type A connector.

The header of the dialog, placed at the top, consists of:
      • the filtering options for each type,
      • a single search text field for all the boards,

The filtering options are similar for each of the three types. They consist of

        •   the Visibility Button     activate/deactivate the boards’ visibility,

3.3.3.1 Power Filters




                     Figure 16: ST MC Workbench – New Project Window – Board Selection Power Filters




The Power Cards displayed in the dialog can be filtered with specific filters for this type of hardware, using
the relative filter button placed on the header of the dialog.

Power filters can filter powers based on:

    •   Features: it refers to the power kind of feature that the board can implement. It supports multiple
        selections in case multiple features are needed in a single board;
    •   Connector type: it refers to the type of connector that the board is provided with. The supported
        types of connectors are Morpho connector, MotorControlConnector connector or PCIe connector;
    •   Rated Voltage: it refers to the voltage range at which the board is projected to work with;
    •   Rated Current: it refers to the current range at which the board is projected to work with;
    •   User boards only: it filters out the provided hardware, showing only the custom user boards.

The number of active filters is shown as a red bubble on top of the Filters icon. By clicking on it, all the filters
can be reset, as shown by the bubble UI when hovered by the mouse. Each filter can also be reset singularly
by the relative buttons.

3.3.3.2 Control Filters
                     Figure 17: ST MC Workbench – New Project Window – Board Selection Control Filters




The Control Cards displayed in the dialog can be filtered with specific filters for this type of hardware, using
the relative filter button placed on the header of the dialog.

Control filters can filter controls based on:

    •   Features: it refers to the control kind of feature that the board can implement. It supports multiple
        selections in case multiple features are needed in a single board;
    •   Number of connectors: it refers to the number of connectors available to connect the board to the
        powers or adapters. It can have up to two connectors.
    •   MCU family: it refers to the family of the MCU built in the relative hardware. It supports multiple
        selection in case different families of control hardware need to be shown at the same time;
    •   User boards only: it filters out the provided hardware, showing only the custom user boards.

The number of active filters is shown as a red bubble on top of the Filters icon. By clicking on it, all the filters
can be reset, as shown by the bubble UI when hovered by the mouse. Each filter can also be reset singularly
by the relative buttons.

3.3.3.3 Inverter Filters
The Inverter Cards displayed in the dialog can be filtered with specific filters for this type of hardware, using
the relative filter button placed on the header of the dialog.




                     Figure 18: ST MC Workbench – New Project Window – Board Selection Inverter Filters

Inverter filters can filter inverters based on:

    •   Control Features: it refers to the control kind of feature that the board can implement. It supports
        multiple selections in case multiple features are needed in a single board;
    •   Power Features: it refers to the power kind of feature that the board can implement. It supports
        multiple selections in case multiple features are needed in a single board;
    •   Number of motor drives: it refers to the number of motor drives available to connect the board to
        the motors. It can have up to two motor drives;
    •   MCU family: it refers to the family of the MCU built in the relative hardware. It supports multiple
         selection in case different families of hardware need to be shown at the same time;
    •    Rated Voltage: it refers to the voltage range at which the board is projected to work with;
    •    Rated Current: it refers to the current range at which the board is projected to work with;
    •    User boards only: it filters out the provided hardware, showing only the custom user boards.

The number of active filters is shown as a red bubble on top of the Filters icon. By clicking on it, all the filters
can be reset, as shown by the bubble UI when hovered by the mouse. Each filter can also be reset singularly
by the relative buttons.

Selecting a card with a single click and then pressing the Ok button (       ) placed on bottom right, or simply

3.7 Project wizard
The project wizard is accessible from the left pane items or the main schematic view. Clicking on one of
these items, the full wizard pop-up and the relative step will be shown. The wizard is customized depending
on the selected algorithm, though all the steps are always available having the user being able to freely
move over all of them. The project wizard is the smart way to customize and configure the motor control
application. Each wizard step contains several checks and info that help the user make the right
configurations; in case of errors the wizard doesn’t allow to apply the edits made, asking the user to fix the
problems before applying them. In any case, the firmware project generation is not allowed if any kind of
error is found.

The step sequence on the wizard has a specific meaning: the value of any field in any given step needs to
be compatible with all the parameters set in the previous steps (while parameters of the following steps
have no importance). The same dependency is also applied within fields inside the same step: the bounding
hierarchy always follow the simple “from top to bottom, from left to right” rule.

In case of multi motors application projects, the wizard shows the steps grouped by motor (stage). A “Stage”
is a logical concept that identifies a full set composed by the interconnection of the Motor Drive, Power
board, eventual connector(s) and/or bridge and Control board, that can make the motor spin.
